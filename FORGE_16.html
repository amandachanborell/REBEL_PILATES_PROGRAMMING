Class Theme
Layers — Base Move + Add On
Each exercise is split into two parts. Spend 30 seconds on the base move to establish the pattern and load, then add the layered movement on top for another 30 seconds. Follow the video to see exactly how each layer builds.
Playlist Vibe
Upbeat, gritty, cool. Tempo between 90-120 bpm. Uplifting warm up with a relaxing cool down.
Class Intro
Welcome to Forge. Today's class has a Layers theme — every exercise starts with a base move, then we add on. You'll get 30 seconds to establish the pattern, then 30 seconds to layer it up. We're working with the Ball and a medium-heavy dumbbell across a unilateral format. Controlled, intentional, and powerful. Let's go.
